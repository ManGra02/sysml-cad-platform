# SysML v2 test models

Mostly commit payloads (`{"change": [{"identity": ..., "payload": ...}]}`) as the SysML v2 API
accepts them. Load into Flexo from `backend/`:

| File | What | Load |
| --- | --- | --- |
| `ebike_demo.json` | E-bike drive unit, made for this project: 11 parts, 11 attributes with units, 3 requirements with satisfy links, 1 interface. Generated by `app/sysml/demo.py` (`build_ebike()`); a simplified subset of the metamodel. | `uv run python -m app.sysml seed-demo` |
| `PartsTreeRedefinition.json` | Flexo's own test model (vehicle, axles, wheels, `mass = 1750 [kg]`), exported from the SysML v2 Pilot. Apache-2.0, see `flexo/NOTICE`. | `uv run python -m app.sysml seed-demo --model parts-tree` |
| `cube_freecad.sysml` | Textual notation: a cuboid with three upper bounds (`100 [mm]` ...) and satisfy links, from the bidirectional-sync PoC. Needs the SysML kernel (see `flexo/README.md`). | `uv run python -m app.sysml import-sysml ../data/examples/sysml/cube_freecad.sysml` |
| `bds/gearbox.json`, `bds/motor_housing.json`, `bds/cube.json` | The BDS example models from the bidirectional-sync PoC (packages `Gearbox`, `MotorHousing`, `CubeFreecad`): parts with typed attributes, requirement definitions with constraints and units, satisfy links (incl. dotted paths). Element lists as the SysML v2 Pilot published them -- the full metamodel BDS reads. | `create-project "Gearbox"`, then `load-file "Gearbox" ../data/examples/sysml/bds/gearbox.json` |

Your own model as a `.sysml` file: `uv run python -m app.sysml import-sysml path/to/model.sysml`
(or the "Import .sysml" button on the SysML page) -- one new project per import. As JSON:
`uv run python -m app.sysml create-project "My Model"` and
`uv run python -m app.sysml load-file "My Model" path/to/model.json`.
